## À propos de React Todo App

React Todo App est une application web moderne de gestion de tâches construite avec les technologies les plus récentes. Elle démontre les meilleures pratiques React avec une architecture propre et maintenable.

### Caractéristiques principales

- **Authentification flexible** : Email, Google OAuth, ou connexion anonyme
- **Synchronisation en temps réel** : Les tâches sont mises à jour instantanément grâce à Firebase
- **Upload de fichiers** : Téléchargez et compressez des fichiers
- **Gestion d'état moderne** : Context API pour une gestion d'état prévisible
- **Performance optimisée** : Construit avec Vite pour un build ultra-rapide

### Pourquoi React Todo App ?

Ce projet est parfait pour :
- **Apprendre React** : Voir les meilleures pratiques avec les hooks et Context API
- **Comprendre Firebase** : Intégration complète de la base de données temps réel et authentification
- **Explorer Vite** : Découvrir le bundler next-gen pour une excellente expérience développeur
- **Référence d'architecture** : Un exemple de structure de projet bien organisée

## Prérequis

Avant de commencer, assurez-vous d'avoir :

- **Node.js** 18+ installé ([nodejs.org](https://nodejs.org))
- **npm** ou **yarn** pour gérer les dépendances
- Un compte Firebase gratuit ([firebase.google.com](https://firebase.google.com))
- Connaissances de base en JavaScript et React
